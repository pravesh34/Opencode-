Welcome to Open Gateway

This is the local web app that the Android WebView wrapper loads. It includes a **real host shell** (Mac zsh / Termux bash — auto-detected) and **OpenCode** (`opencode run`) wired over the local WebSocket — not just a demo. Locally it runs on localhost:3000 with a WebSocket gateway on :8080/ws (also proxied at /ws on :3000).

Quick actions

Terminal: the host's own shell (Mac: zsh, Termux: bash) — try ls, pwd, cd web && ls, opencode run "hi". OpenCode: streaming assistant powered by the local opencode CLI.

For the Android app

On an emulator, 10.0.2.2:3000 maps to this host's localhost:3000. On a physical device, use your LAN IP (e.g. http://192.168.1.x:3000) or a tunnel URL. The app has an in-app URL editor so you don't need to rebuild to change it.

The host's own shell (cwd tracked per session). cd persists within the session. Quick: ls · pwd · whoami · date · clear (client-side) · opencode run "…".

Powered by local opencode run CLI. Session is kept so follow-ups continue the same conversation. Use New session to reset.
